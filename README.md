# Simulasi ASAS — Matematika SMP Kelas 7

Simulasi Asesmen Sumatif Akhir Semester (ASAS) Matematika Kelas 7, SMP Negeri 2 Sendang Agung.
Soal dari Kunci Jawaban & Pedoman Penskoran ASAS Matematika Kelas VII TP 2025/2026 — MGMP Matematika SMP Kabupaten Lampung Tengah.

**Coba langsung:** https://holizon-sendang.github.io/simulasi-asas-mtk-smpn2sendangagung/

## Isi simulasi

- 40 soal: 20 Pilihan Ganda, 5 Benar/Salah, 5 Menjodohkan, 5 Isian Singkat, 5 Uraian
- Materi Semester 1 Kelas 7: Bilangan Bulat (12), Bilangan Rasional (10), Aritmetika Sosial (8), Perbandingan (10)
- Timer 120 menit, jawaban otomatis dikumpulkan saat waktu habis (lanjut setelah refresh)
- Nilai otomatis 35 soal (maks 70) + uraian dinilai mandiri 0-6 per soal (maks 30), total /100, KKM 70
- Riwayat skor tersimpan di perangkat siswa
- Pengiriman nilai ke Google Sheets (satu baris per siswa) — lihat `PANDUAN-GOOGLE-SHEETS.md`

## File

- `index.html`, `style.css`, `script.js` — halaman simulasi
- `assets/css/main.css`, `assets/js/main.js` — gaya dan skrip dasar MPI Matematika SMP
- `kode-apps-script.gs` — kode Apps Script untuk pengiriman nilai ke Google Sheets
- `PANDUAN-GOOGLE-SHEETS.md` — panduan guru: membuat Sheet, deploy Web App, menempel URL
